# Project constraints

- Keep this package free of bundled icons and artwork. Do not add icon libraries, brand/logo assets, SVG path datasets, icon fonts, embedded image assets, or runtime icon downloads.
- Sharing controls must use readable text labels. Preserve accessible styling, keyboard behavior, and the framework-independent sharing APIs.
- Use `ext@ozdemir.dev` for the package author email and `ozdemirburak@users.noreply.github.com` for Git attribution.
- Run `npm run check` before handing off changes. Check the actual packed archive, including generated bundles and source maps, for excluded artwork and stale assets.
